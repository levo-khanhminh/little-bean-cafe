# Little Bean Cafe

A tiny React website used as a Git practice project.

## Run it on your computer

```bash
npm install
npm run dev
```

Then open the address shown in the terminal (usually http://localhost:5173).

## Where things live

| What | File |
|---|---|
| Menu items and prices | `src/data/menu.json` |
| Shop name and opening hours | `src/data/shop.json` |
| How one menu row looks | `src/components/MenuItem.jsx` |
| Page layout | `src/App.jsx` |

Most exercises only change `src/data/menu.json`.
